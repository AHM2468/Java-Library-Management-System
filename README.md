# Library Management System (Java - OOP)

A console-based Library Management System built using Java to demonstrate Core Object-Oriented Programming (OOP) concepts.

## 🚀 Features
- **Book Management:** Add new books with unique attributes (Title, Author, Availability).
- **Borrow & Return System:** Clients can borrow available books or return them, dynamically updating status.
- **Advanced Search:** Search for books flexibly by title or author keywords.
- **Robust Error Handling:** Validates inputs using `try-catch` blocks to handle exceptions (`InputMismatchException`).

## 🛠️ Tech Stack & Concepts
- **Language:** Java
- **Data Structures:** ArrayList & List
- **OOP Concepts:** Encapsulation, Classes & Objects
